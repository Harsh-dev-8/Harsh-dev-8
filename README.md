## 🚀 Project

### [Library Management System](https://github.com/Harsh-dev-8/Library-Management-project)

A full-stack library system with librarian and member roles, borrowing limits and automatic late-fine calculation. My first complete project.

- Custom user model with librarian and member roles
- Borrow and return flow with a 5-book limit and automatic fines
- Session authentication with CSRF protection across separate frontend and backend domains
- 23 automated tests and Swagger API docs
- Backend deployed on Render, frontend on Netlify

**[Live demo](https://harsh-library.netlify.app/)** · **[API docs](https://library-3o9m.onrender.com/api/docs/)** · **[Source code](https://github.com/Harsh-dev-8/Library-Management-project)**

*The backend runs on a free tier, so the first load can take up to a minute.*
